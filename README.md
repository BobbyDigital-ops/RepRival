# RepRival v1.4.9 — Movement league sandbox

This release builds on **v1.4.8**, adding a fully local, interactive league **simulation**. It does **not** connect athletes to each other, register real users, create public leaderboards or upload workout data.

## New in 1.4.9

- **Leagues** tab and a compact shortcut on Home.
- A deterministic pool of **10,000 fictional UK athletes**, generated by ID without saving 10,000 complete profiles. Only the opponents in relevant mini leagues are calculated on demand.
- **Separate mini leagues for each movement**. Each league contains up to 14 fictional rivals plus your athlete. Initial division is provisionally seeded from your existing personal Athlete Rating; movement-specific rankings use your actual best logged qualifying set.
- Rival identities, locations, performance patterns and 6-hour simulation updates are reproducible between sessions. Rivals may fluctuate over time; they are not real people.
- **Promotion:** Reach first place in a movement, then hold it for **24 continuous hours**. If a simulated rival overtakes you, your countdown resets. Promotion moves you only in that movement's division ladder.
- **Inactivity:** The first 14 days are protected. After day 14, your displayed Athlete Rating gradually decays and promotions are paused. After 30 days without a completed workout, all your active league places are relinquished. Logging a new workout enables re-entry, with a new mini-league seed when the recorded gap was over 30 days. Previous divisions and logged PBs remain in your own history.
- Optional **display town** selection. Matchmaking is still by simulated ability across the UK; **no postcode or precise coordinates** are collected.
- Simulation preferences and progress are saved *within each existing local athlete profile* under `leagueSim`. They are included in full backup exports.
- All exercise illustrations remain bundled and work without external asset requests. Existing rotation progress and recovery guide remain unchanged.

## How to use

1. Open **Leagues** in the bottom navigation (or the shortcut on Home).
2. Use **Exercise league** to choose a movement. Movements without logged sets are shown as **Unranked**.
3. Record an actual workout in the existing Workout section. Your completed sets automatically update the corresponding league the next time it is opened.
4. Improve a movement's recorded best-set score to climb the rankings. Hold #1 for 24 hours to promote in that **specific** movement.
5. Choose a town in **Competition settings** if you want more nearby fictional opponents.

## Important limits

- This is **not multiplayer**. Another installation does not compete against the same live people. All opponents are clearly marked simulated.
- Division seeding is approximate: current Athlete Rating reflects personal improvement, not absolute strength. Opponents are seeded around the movement's initial recorded performance.
- Weighted-set scores use the app's existing approximate 1RM estimator (weight × (1 + reps/30), capped at 30 reps), and bodyweight movements use recorded repetitions. Mixed equipment, form, RIR and technique are not externally verified. The simulation is for testing engagement and gameplay, not an authoritative strength ranking.
- League timers and rivalry changes use the local device clock, checked at simulated 6-hour opponent-update boundaries when RepRival runs. Local clock changes and localStorage edits can manipulate this version; server validation will be essential before real competitive launch.
- No paid cloud services or real user accounts are needed to try this release.

## Deploy on GitHub + Netlify

1. **Before updating, open the existing live Netlify app and export a complete JSON backup.** Download it somewhere safe. This update does not automatically migrate data between different domains or different browser storage origins.
2. Download and extract `RepRival_v1_4_9_GitHub_Update.zip`.
3. Upload **the contents of the extracted ZIP** into the root of the existing RepRival GitHub repository, replacing matching files. Ensure the new `leagues.js` file is uploaded alongside `app.js` and `index.html`.
4. Commit the changes and allow Netlify to deploy. The site header should say **LEAGUE SANDBOX · 1.4.9**.
5. Verify your old workouts and profile still exist. **Do not clear browsing/site data, remove the installed app, or change the domain**, as your existing workouts are stored locally.

The localStorage key remains **`reprival-athletes-v12`**, the top-level profile schema remains **version 12**, and completed workout records are not overwritten.
